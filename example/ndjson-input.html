The same loadLog(text) entry point now accepts CSV or NDJSON — the format is auto-detected from the content (detectLogFormat), so the same call renders the same diagram either way. Switch the format control to re-fetch events.csv / events.json; the auto-detected badge shows what the library decided. The IndexedDB cache (see the log-cache demo) still applies — a reload of the same bytes is fromCache: true. URL params: ?format=csv|json (default json), ?w=800&h=600 sets the host pixel size; ?fixture=n5-fixture (default) or ?fixture=n1000-realistic; ?topK=N sets the variant-panel default selection; ?preset=default|linear|paper picks a named preset; ?accent=ec4899 overrides the accent colour; ?controls=mode variants filters tr bl selection hides specific surfaces.
