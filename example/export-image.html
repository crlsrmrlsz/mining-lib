mining-lib · export diagram as image (ESM source)

Every earlier feature still applies (count / time modes, theme toggle, variant / filter / date / case controls, NDJSON auto-detect, IndexedDB cache). New here: export the full filtered graph as a self-contained image. Use the ⤓ icon in the bottom-right utilities pill (SVG / PNG menu) or the explicit buttons below — both call handle.exportSvg() / handle.exportPng(). The export captures the whole diagram at the current data state (filters, overlays, theme), ignoring transient pan / zoom. URL params: ?format=csv|json (default json), ?w=800&h=600 sets the host pixel size; ?fixture=n5-fixture (default) or ?fixture=n1000-realistic; ?topK=N sets the variant-panel default selection; ?preset=default|linear|paper picks a named preset; ?accent=ec4899 overrides the accent colour; ?controls=mode variants filters tr bl selection hides specific surfaces.
